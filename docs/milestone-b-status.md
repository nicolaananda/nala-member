# Milestone B — pelaksanaan per fase

Nicola meminta satu fase dikerjakan sampai selesai sebelum berpindah ke fase berikutnya agar mudah dipantau. Setiap laporan fase memisahkan implementasi, pengujian, dan rilis.

| Fase | Scope | Status |
|---|---|---|
| B6 | Tugas/petunjuk per materi, revisi dan riwayat, antrean/filter evaluasi, rubrik/nilai/masukan/saran latihan, status dibaca | Dalam pengerjaan; revisi API/UI tersedia, tes PostgreSQL dan build lulus; belum acceptance browser atau rilis |
| B7 | Kuis opsional pilihan ganda/benar-salah, penilaian server, batas percobaan, minimum nilai, riwayat, pembahasan, integrasi kelulusan | Belum dimulai |
| B8 | Notifikasi portal/deep link, pengumuman/pengingat, preferensi email, Q&A privat scoped, status jawaban, deduplikasi/status pengiriman | Belum dimulai |
| B9 | Tantangan terjadwal, pengumpulan/penilaian, galeri pilihan, consent/moderasi/laporan/pencabutan | Belum dimulai |
| B10 | Jalur/prasyarat, syarat kelulusan, sertifikat unduh/cetak/verifikasi/pencabutan, badge | Belum dimulai |

Fitur existing digunakan ulang, bukan dibangun ulang. Pengujian menggunakan database terisolasi. Kelas lama tidak otomatis dikunci; publikasi karya tetap opt-in. Produksi masih Milestone A.
